# 🎯 Number Guessing Game

A clean, modern, and responsive Number Guessing Game built with vanilla HTML5, CSS3, and JavaScript.

## 🚀 Features

- **3 Difficulty Levels**:
  - **Easy**: Numbers between 1 and 50 (10 attempts)
  - **Medium**: Numbers between 1 and 100 (7 attempts)
  - **Hard**: Numbers between 1 and 200 (5 attempts)
- **Interactive Feedback**: Instant hints on whether your guess is too high or too low.
- **🏆 High Score Tracking**: Best score is saved locally via browser `localStorage`.
- **📱 Responsive UI**: Clean dark theme optimized for mobile and desktop screens.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Flexbox, CSS Grid, Custom Animations)
- **JavaScript (ES6+)** (DOM Manipulation, LocalStorage, Event Handling)

## 🎮 How to Play

1. Choose a difficulty level (**Easy**, **Medium**, or **Hard**).
2. Enter your guess in the input box and hit **Submit Guess** or press **Enter**.
3. Follow the hints (`Too High` / `Too Low`).
4. Guess the secret number before your attempts run out!
